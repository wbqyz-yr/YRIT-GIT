# 五子棋 (Gomoku)

一个纯前端、无依赖的五子棋小游戏。15×15 标准棋盘，支持双人对战和人机对战。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖：

```bash
# 或使用任意静态服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 功能

- **双人对战**：两名玩家轮流落子。
- **人机对战**：可选电脑执黑或电脑执白，电脑会主动进攻并防守。
- **悔棋**：撤销一步（人机模式下会一次撤回双方各一手）。
- **胜负判定**：先连成五子者胜，高亮获胜连线。
- **重新开始**：随时重置棋盘。
